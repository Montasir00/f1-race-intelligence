# Data Directory & Reproducible Download Procedure

This folder stores cached API payloads and processed analytical tables:

- `raw/`: Cached JSON responses from the **Jolpica F1 API** (`https://api.jolpi.ca/ergast/f1`) and **OpenF1 API** (`https://api.openf1.org/v1`). Ignored by Git (except `.gitkeep`) to keep the repository lightweight.
- `processed/`: Cleaned, merged CSV tables (`results`, `laps`, `pitstops`, `stints`) generated by `f1_analysis.pipeline`. Ignored by Git (except `.gitkeep`).

## Reproducible Download Command

From the project root, run:

```bash
python scripts/download_data.py --year 2024 --rounds 1 2 3
```

What this script does:
1. Downloads and caches the 2024 season calendar (`jolpica_2024_calendar.json`).
2. Pages through Jolpica (`limit=100` with `offset` pagination, validating row count against `MRData.total`) to retrieve complete race classifications, every lap timing (~1,000+ rows per race), and all pit stops.
3. Matches each race date to its **OpenF1** session key (`session_name="Race"`) and caches tyre stint records (`openf1_session_<key>_stints.json`).
4. Runs the cleaning, fuel-load correction, and driver-number stint join pipeline and writes the processed CSV files into `data/processed/`.
